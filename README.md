⚡ ECE Circuit Calculator

A simple Python-based circuit calculator designed for Electronics and Communication Engineering students.

Features

- Calculate Voltage using Ohm's Law
- Calculate Current
- Calculate Resistance
- Calculate Electrical Power
- Menu-driven interface
- Handles invalid division by zero

Formulas Used

Ohm's Law

V = I × R

Where:

- V = Voltage (Volts)
- I = Current (Amperes)
- R = Resistance (Ohms)

Electrical Power

P = V × I

Where:

- P = Power (Watts)
- V = Voltage (Volts)
- I = Current (Amperes)

Technologies Used

- Python

How to Run

1. Clone the repository:

git clone YOUR_REPOSITORY_LINK

2. Navigate to the project folder:

cd ece-circuit-calculator

3. Run the program:

python main.py
